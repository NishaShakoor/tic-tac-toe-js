# Tic-Tac-Toe Game

A simple, interactive Tic-Tac-Toe game built with vanilla JavaScript, HTML, and CSS.

## Features
- Player vs Computer gameplay
- Responsive design with orange/yellow theme
- Win/lose/draw detection
- Reset game functionality
- Computer AI with random move selection

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## How to Play
1. Open `index.html` in your browser
2. Click on any square to make your move (X)
3. Computer automatically plays as O
4. First to get 3 in a row wins!
5. Use Reset button to start a new game

## Installation
1. Clone this repository
2. Open `index.html` in your web browser
3. Start playing!
